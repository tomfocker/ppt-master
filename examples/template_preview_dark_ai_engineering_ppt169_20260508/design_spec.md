# Dark AI Engineering Preview - Design Specification

## I. Template Overview

| Field | Value |
|---|---|
| Template | `dark_ai_engineering` |
| Purpose | 样例预览：展示暗色 AI 工程风格在真实内容页中的效果 |
| Audience | 技术负责人、产品安全团队、工程评审委员会 |
| Page Count | 5 pages |
| Format | PPT 16:9 |

## II. Visual Direction

深色工程界面风格，使用近黑背景、蓝色结构线、青色高亮和少量风险提示色。页面以系统架构、风险矩阵、指标卡片、流程节点为主，避免装饰性图片，强调可编辑 SVG 元素。

## III. Content Outline

1. 封面：Auto Mode 安全评审样例
2. 架构总览：输入探针、权限分层、输出分类器
3. 风险矩阵：四类风险与处理策略
4. 指标面板：误报率、拦截率、延迟、覆盖层级
5. 结束页：模板可复用说明
